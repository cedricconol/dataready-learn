# Terminal

The terminal is where data analysts do their most powerful work. SQL queries run in it. Python scripts run in it. dbt runs in it. Version control runs in it. Once you are comfortable with the terminal, every other tool becomes easier to use.

## What You'll Learn

- Navigating the filesystem (`pwd`, `ls`, `cd`)
- Creating, copying, moving, and deleting files
- Reading file contents without opening a text editor
- Searching for text inside files with `grep`
- Combining commands with pipes to build one-liners
- Manipulating text data directly on the command line
- Understanding file permissions and ownership
- Managing processes and environment variables
- Writing your first shell scripts

## How This Works

Each lesson explains a command or concept, then drops you into an **interactive terminal playground** at the bottom of the page. The playground runs a real shell (in your browser — no server required) against a pre-built filesystem.

Your goal for each lesson appears in the left panel. When the sandbox detects that you have completed it, the lesson is marked done and the next one unlocks.
