# Exam 3: Filtering Techniques

**Difficulty:** Beginner+

**Topics covered:** `IN`, `NOT IN`, `BETWEEN`, `LIKE`, `IS NULL`

Each question shows the target output. Write a SQL query that produces exactly those columns and rows.

---
