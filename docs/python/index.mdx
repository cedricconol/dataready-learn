# Python

## Why does this track exist?

A colleague sends you a CSV file with 300,000 rows of sales records. Excel opens the file, but then it becomes very slow. You build a pivot table. The pivot table answers half of your question. Then your manager asks a question that a pivot table cannot answer: "For each customer, what changed between the first order and the second order?"

**Python and the pandas library do this work.** Analysts use pandas to load, clean, reshape, and analyze tabular data. Pandas can hold data that is too large or too irregular for a spreadsheet. You write code instead of clicking through menus.

After you learn to write this line:

```python
orders.groupby("status")["total_amount"].sum()
```

you can answer in one line a question that needs twelve steps in a spreadsheet. The code is also repeatable. Next month you run the same code again. You do not do the work again.

Pandas is the most-used data tool in Python. It connects two skills: you can look at data, and you can build things with data. These things include scripts, dashboards, and models.

## What You Learn

- Load, inspect, and select data with Series and DataFrames
- Filter, sort, and clean data that contains errors
- Combine more than one dataset
- Aggregate and summarize data by group
- Reshape data between long format and wide format
- Calculate rolling values, ranks, and time-based results
- Write pandas the way that experienced analysts write it: vectorized, chained, and readable
- Choose between pandas and SQL, and use both together

:::info You do not need SQL first
This track is complete on its own. If you completed the [SQL track](/sql), you will see notes with the title "Coming from SQL?". Each note connects a pandas idea to the equivalent SQL. These notes are optional. Skip them if you do not know SQL.
:::

:::tip This course teaches pandas 3.0
Every lesson uses pandas 3.0 conventions: Copy-on-Write, the string dtype, and `pd.col()`. You will not have to learn different habits later. The playground at the end of each lesson runs pandas 3.0 in your browser. You install nothing.
:::

## The Sample Data

Every lesson and every exercise uses the same three tables. The playground loads them as DataFrames with the names `customers`, `products`, and `orders`.

| DataFrame | Rows | What it holds |
|-----------|------|---------------|
| `customers` | 9 | One row per customer: name, email, city, country, signup date |
| `products` | 6 | One row per product: name, category, price |
| `orders` | 30 | One row per order: who bought what, when, how many, and for how much |

The data contains problems on purpose. One customer has no city. Two orders have no status. One order has no amount. One customer made no orders. Real data has the same problems, and an analyst spends much of the day on them.
