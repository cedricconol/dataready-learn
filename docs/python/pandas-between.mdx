# `between`: Range Filtering

You use ranges very often: orders in a price band, dates in a quarter, or quantities in a group. `between` replaces two comparisons with one comparison.

## Syntax

```python
df[df["column"].between(low, high)]
```

By default, `between` **includes both end values**. `between(100, 500)` therefore includes the rows with the value 100 and the rows with the value 500.

## Example

These two lines give the same result:

```python
amount = orders["total_amount"]

orders[(amount >= 100) & (amount <= 500)]
orders[amount.between(100, 500)]
```

## How to control the end values

The `inclusive` argument accepts `"both"` (the default), `"neither"`, `"left"`, or `"right"`:

```python
amount = orders["total_amount"]
orders[amount.between(100, 500, inclusive="neither")]
```

This code removes each row with the value 100 or the value 500. With this data the result is the same, because no order has one of these two values. But with real data, "up to 500" and "less than 500" give different results. A reviewer of your report will find this difference.

## `between` also works on dates

`order_date` is a date column, so you can give `between` two dates as text:

```python
date = orders["order_date"]
orders[date.between("2024-02-01", "2024-02-29")]
```

**Result:**

|   | order_id | customer_id | product_id | order_date | quantity | total_amount | status |
|---|----------|-------------|------------|------------|----------|--------------|--------|
| 6 | 7 | 1 | 3 | 2024-02-01 | 1 | 349.0 | cancelled |
| 7 | 8 | 5 | 2 | 2024-02-04 | 3 | 89.97 | completed |
| 8 | 9 | 3 | 1 | 2024-02-09 | 1 | 999.0 | pending |
| 9 | 10 | 6 | 5 | 2024-02-14 | 5 | 24.95 | completed |
| 10 | 11 | 2 | 1 | 2024-02-18 | 1 | 999.0 | completed |
| 11 | 12 | 7 | 6 | 2024-02-23 | 1 | 249.0 | completed |
| 12 | 13 | 4 | 4 | 2024-02-27 | 2 | 398.0 | completed |

The result has the seven orders from February. This code works only because the column is a `datetime64` column. If the column were text, pandas would compare `"2024-02-09"` in alphabetical order. Alphabetical order gives the correct result for this date format, but it gives incorrect results for other date formats.

:::warning Write the low value first
`between(500, 100)` returns no rows. Pandas does not change the order of your arguments. It finds no row that is both above 500 and below 100.
:::

:::note Coming from SQL?
`between` is `WHERE total_amount BETWEEN 100 AND 500`. Both languages include the end values.
:::
