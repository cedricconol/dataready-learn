# `isin`: Filtering Against a List

Sometimes you want the rows that match one value from a set of values. A long chain of `|` operators is difficult to read. `isin` does the same work in one call.

## Syntax

```python
df[df["column"].isin([value1, value2, value3])]
```

Put the values in a list, inside square brackets. Do this for two values also.

## Example

Do not write this code:

```python
status = orders["status"]
orders[(status == "pending") | (status == "cancelled")]
```

Write this code:

```python
orders[orders["status"].isin(["pending", "cancelled"])]
```

**Result:**

|   | order_id | customer_id | product_id | order_date | quantity | total_amount | status |
|---|----------|-------------|------------|------------|----------|--------------|--------|
| 6 | 7 | 1 | 3 | 2024-02-01 | 1 | 349.0 | cancelled |
| 8 | 9 | 3 | 1 | 2024-02-09 | 1 | 999.0 | pending |
| 15 | 16 | 5 | 3 | 2024-03-11 | 1 | 349.0 | cancelled |
| 22 | 23 | 4 | 6 | 2024-04-12 | 2 | 498.0 | pending |

The result is the same, and `isin` becomes better as the list becomes longer. For ten values you write ten conditions, or you write one `isin`.

## `isin` also works on numbers

The list can hold numbers. `isin` behaves in the same way:

```python
customers[customers["customer_id"].isin([1, 3, 5])]
```

**Result:**

|   | customer_id | name | email | city | country | signup_date |
|---|-------------|------|-------|------|---------|-------------|
| 0 | 1 | Alice Johnson | alice@example.com | New York | USA | 2023-11-02 |
| 2 | 3 | Carol White | carol@example.com | Sydney | Australia | 2024-01-08 |
| 4 | 5 | Eve Davis | eve@example.com | New York | USA | 2024-02-03 |

Use this method to select a set of records from a large table when you know the IDs.

## How to exclude a list

Write `~` before the condition. Pandas then keeps the rows that are *not* in the list:

```python
customers[~customers["country"].isin(["USA", "UK"])]
```

**Result:**

|   | customer_id | name | email | city | country | signup_date |
|---|-------------|------|-------|------|---------|-------------|
| 2 | 3 | Carol White | carol@example.com | Sydney | Australia | 2024-01-08 |
| 3 | 4 | Dave Brown | dave@example.com | Toronto | Canada | 2024-01-20 |
| 6 | 7 | Grace Kim | grace@example.com | Seoul | South Korea | 2024-02-01 |
| 7 | 8 | Henry Cruz | henry@example.com | Manila | Philippines | 2024-02-10 |
| 8 | 9 | Ivy Nakamura | ivy@example.com | Tokyo | Japan | 2024-04-02 |

Exclusion is often the easier method. Usually you remove a small number of values. That list is shorter than a list of every value that you keep.

:::tip A list from a different source
You do not have to type the list. This pattern is common in real work:

```python
big_spenders = [1, 2, 3]
orders[orders["customer_id"].isin(big_spenders)]
```

The list can come from a different DataFrame, a config file, or an earlier step in your analysis.
:::

:::warning The match is exact
`isin(["Pending"])` does not match `"pending"`. The letter case is important, and extra spaces are also important. If a filter returns no rows, print `df["column"].unique()` and examine the real values.
:::

:::note Coming from SQL?
`isin` is `WHERE status IN ('pending', 'cancelled')`. `~...isin(...)` is `NOT IN`.
:::

## Practice

Return every product in the `Furniture` category or the `Stationery` category.

<details>
<summary>Show answer</summary>

```python
# isin() takes a list and tests each row against every
# value in it, so one call replaces a chain of | tests.
wanted = ["Furniture", "Stationery"]

products[products["category"].isin(wanted)]
```

**Result:**

|   | product_id | name | category | price |
|---|-----------|------|----------|-------|
| 2 | 3 | Desk | Furniture | 349.0 |
| 3 | 4 | Chair | Furniture | 199.0 |
| 4 | 5 | Notebook | Stationery | 4.99 |
