## Question 1

Build a grid of the total revenue. Put `category` down the side and `status` across the top. Put a zero in each cell that has no data.

<PythonExercise
  frames={["orders", "products"]}
  solution={`# The category lives in products, so merge it in first.
sales = orders.merge(products, on="product_id")

sales.pivot_table(
    index="category",      # goes down the side
    columns="status",      # goes across the top
    values="total_amount",
    aggfunc="sum",
    fill_value=0,          # write 0, not NaN, when empty
)`}

## Question 2

Build a grid of order **counts**. Put `customer_id` down the side and `status` across the top. Put a zero in each empty cell. Use `unstack` for this question. A `pivot_table` gives the same grid, and the check accepts it, but this question is about `unstack`.

<PythonExercise
  frames={["orders"]}
  solution={`# Group by both columns at once.
group_keys = ["customer_id", "status"]

# size() counts rows, so no value column is needed.
counts = orders.groupby(group_keys).size()

# unstack moves "status" up into the columns.
counts.unstack(fill_value=0)`}
/>

## Question 3

What is the average order value of each product category? Return a table with one column, rounded to two decimals.

<PythonExercise
  frames={["orders", "products"]}
  solution={`sales = orders.merge(products, on="product_id")

# With no columns= argument, pivot_table is a grouped
# summary rather than a grid.
sales.pivot_table(
    index="category",
    values="total_amount",
    aggfunc="mean",
).round(2)`}
/>

## Question 4

Take the customer-by-status count grid from Question 2. Melt it into a long table with the columns `customer_id`, `status`, and `orders`.

<PythonExercise
  frames={["orders"]}
  solution={`# 1. Build the count grid.
group_keys = ["customer_id", "status"]
counts = orders.groupby(group_keys).size()

# reset_index() makes customer_id a column again, so melt
# can use it as an id column.
wide = counts.unstack(fill_value=0).reset_index()

# 2. Melt every status column back into rows.
wide.melt(
    id_vars="customer_id",
    var_name="status",
    value_name="orders",
)`}
/>
