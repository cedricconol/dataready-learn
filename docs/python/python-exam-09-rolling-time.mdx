## Question 1

What is the total revenue of each calendar month? Group the rows by the month number and round the values to two decimals.

<PythonExercise
  frames={["orders"]}
  solution={`# .dt.month takes the month number from each date.
month = orders["order_date"].dt.month

by_month = orders.assign(month=month).groupby("month")
by_month["total_amount"].sum().round(2)`}
/>

## Question 2

Return the columns `order_id`, `total_amount`, and a new `running_total` column. `running_total` adds the revenue from the top of the table to each row. Round the values to two decimals.

<PythonExercise
  frames={["orders"]}
  solution={`# cumsum() adds each row to the sum of the rows above it.
running_total = orders["total_amount"].cumsum().round(2)

with_total = orders.assign(running_total=running_total)

cols = ["order_id", "total_amount", "running_total"]
with_total[cols]`}
/>

## Question 3

Return the first order of each customer. Show the columns `order_id`, `customer_id`, and `order_date`.

<PythonExercise
  frames={["orders"]}
  solution={`# cumcount() numbers the rows inside each customer, from 0.
# Add 1, so the first order is number 1.
order_number = orders.groupby("customer_id").cumcount() + 1

# Keep only the row numbered 1 for each customer.
numbered = orders.assign(order_number=order_number)

cols = ["order_id", "customer_id", "order_date"]
numbered.query("order_number == 1")[cols]`}
/>

## Question 4

Return the columns `order_id`, `total_amount`, and a new `change` column. `change` holds the difference between the row and the previous row. Round the values to two decimals.

<PythonExercise
  frames={["orders"]}
  solution={`# .diff() subtracts the previous row from the current row.
change = orders["total_amount"].diff().round(2)

with_change = orders.assign(change=change)

cols = ["order_id", "total_amount", "change"]
with_change[cols]`}
/>

## Question 5

Resample the orders into monthly revenue. Then return a two-month rolling average, rounded to two decimals.

<PythonExercise
  frames={["orders"]}
  solution={`# 1. One revenue figure for each month, in date order.
monthly = (
    orders
    .set_index("order_date")
    .resample("ME")["total_amount"]
    .sum()
    .round(2)
)

# 2. A two-month window, averaged as it moves down.
monthly.rolling(2).mean().round(2)`}
/>

## Question 6

Use customer 2 only. Return the columns `order_id`, `total_amount`, and a new `rank` column. `rank` holds the position of each order by value inside that customer. Put the largest value first and use dense ranking.

<PythonExercise
  frames={["orders"]}
  solution={`# Rank inside each customer, not across the whole table.
by_customer = orders.groupby("customer_id")

# "dense" gives ties the same rank and leaves no gaps.
rank = by_customer["total_amount"].rank(
    ascending=False, method="dense"
)

ranked = orders.assign(rank=rank)

cols = ["order_id", "total_amount", "rank"]
ranked.query("customer_id == 2")[cols]`}
/>
