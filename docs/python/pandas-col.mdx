# `pd.col`: Columns Inside a Chain

`pd.col` is new in pandas 3.0. It refers to a column by its name, and it does not need the name of the DataFrame.

## How to use it

Write `pd.col("price")` in the place where you would write `products["price"]`:

```python
products.assign(price_with_tax=pd.col("price") * 1.12)
```

**Result:**

|   | product_id | name | category | price | price_with_tax |
|---|-----------|------|----------|-------|----------------|
| 0 | 1 | Laptop | Electronics | 999.0 | 1118.88 |
| 1 | 2 | Mouse | Electronics | 29.99 | 33.5888 |
| 2 | 3 | Desk | Furniture | 349.0 | 390.88 |
| 3 | 4 | Chair | Furniture | 199.0 | 222.88 |
| 4 | 5 | Notebook | Stationery | 4.99 | 5.5888 |
| 5 | 6 | Monitor | Electronics | 249.0 | 278.88 |

`pd.col("price")` means "the column with the name price, in the DataFrame that this code runs on". Pandas reads the column when it runs the line.

The usual operators work on it: `+`, `-`, `*`, `/`, and the comparisons `>`, `<`, `==`.

## In a chain

`pd.col` reads the DataFrame at that step of the chain. This lets you use a column that a step before it made:

```python
(
    products
    .assign(price_with_tax=pd.col("price") * 1.12)
    .assign(
        savings=pd.col("price_with_tax") - pd.col("price")
    )
    .round(2)
)
```

**Result:**

|   | product_id | name | category | price | price_with_tax | savings |
|---|-----------|------|----------|-------|----------------|---------|
| 0 | 1 | Laptop | Electronics | 999.0 | 1118.88 | 119.88 |
| 1 | 2 | Mouse | Electronics | 29.99 | 33.59 | 3.6 |
| 2 | 3 | Desk | Furniture | 349.0 | 390.88 | 41.88 |
| 3 | 4 | Chair | Furniture | 199.0 | 222.88 | 23.88 |
| 4 | 5 | Notebook | Stationery | 4.99 | 5.59 | 0.6 |
| 5 | 6 | Monitor | Electronics | 249.0 | 278.88 | 29.88 |

The first `assign` makes `price_with_tax`. The second `assign` reads it with `pd.col("price_with_tax")`.

## `pd.col` also works in `loc`

```python
orders.loc[pd.col("quantity") > 5]
```

**Result:**

|   | order_id | customer_id | product_id | order_date | quantity | total_amount | status |
|---|----------|-------------|------------|------------|----------|--------------|--------|
| 4 | 5 | 4 | 5 | 2024-01-22 | 10 | 49.9 | NaN |
| 16 | 17 | 3 | 5 | 2024-03-15 | 20 | 99.8 | completed |
| 23 | 24 | 5 | 5 | 2024-04-16 | 15 | 74.85 | completed |
| 26 | 27 | 2 | 5 | 2024-05-02 | 8 | 39.92 | completed |

This filter names the DataFrame one time. In a chain, write `.loc[pd.col("quantity") > 5]` and nothing more.

## Two forms of the same code

```python
# Use the name:
products.assign(is_cheap=products["price"] < 100)

# Use pd.col:
products.assign(is_cheap=pd.col("price") < 100)
```

Both lines make the same column. Use the first form when the DataFrame has a name and the code is short. Use `pd.col` inside a chain, where it is the easiest form to read.

:::warning `pd.col` needs pandas 3.0
`pd.col` does not exist in pandas 2.x. If another machine shows `AttributeError: module 'pandas' has no attribute 'col'`, check `pd.__version__`. Write the name of the DataFrame instead, as in the first form above.
:::

:::note Coming from SQL?
`pd.col("price")` does the same work as a column name in SQL: `SELECT price * 1.12 AS price_with_tax`. SQL never repeats the table name, and with `pd.col`, pandas does not repeat the DataFrame name.
:::

## Practice

Use `pd.col` to add a `unit_price` column to `orders`. The value is `total_amount` divided by `quantity`, rounded to two decimals.

<details>
<summary>Show answer</summary>

```python
# pd.col names a column without naming the DataFrame.
# The brackets make .round(2) apply to the whole division.
unit_price = (
    pd.col("total_amount") / pd.col("quantity")
).round(2)

priced = orders.assign(unit_price=unit_price)

cols = [
    "order_id",
    "quantity",
    "total_amount",
    "unit_price",
]
priced.head(3)[cols]
```

**Result:**

|   | order_id | quantity | total_amount | unit_price |
|---|----------|----------|--------------|------------|
| 0 | 1 | 1 | 999.0 | 999.0 |
| 1 | 2 | 2 | 59.98 | 29.99 |
| 2 | 3 | 1 | 349.0 | 349.0 |

This expression has two `pd.col` references. `.round(2)` applies to the full expression before it becomes a column.

</details>
